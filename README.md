# CareerTrack

A simple, distraction-free **Career Management Dashboard** built to track internship and job applications, upcoming interview dates, and daily topic revision—without the mess of multiple spreadsheets.

**Live Link:** https://suhanapadhi8081.github.io/Career-Track/

## Why I Built This
During placement and internship season, tracking applications across portals, notes, and spreadsheets gets messy fast. I wanted a lightweight, fast dashboard that opens instantly in the browser, highlights upcoming interviews, and keeps my revision checklist right beside my applications.

## What It Does
- **Application Tracker (List & Board Views):** Add, edit, and filter applications by stage (`Wishlist`, `Applied`, `Interviewing`, `Offer`, `Rejected`) and switch between a clean table or Kanban board.
- **Upcoming Interview Alerts:** Automatically flags overdue, today's, tomorrow's, and upcoming interviews so no deadline slips through.
- **Topic Prep Checklist:** Track technical revision topics and see overall preparation progress update in real time.
- **Offline Backup (CSV Export):** Saves everything locally in the browser (`localStorage`) with a one-click option to export data as a `.csv` file for Excel or Google Sheets.

## Built With
- HTML5 & CSS3
- Vanilla JavaScript (`localStorage` for client-side persistence)

## Run Locally
Download or clone the repository and open `index.html` in your browser—no setup or dependencies needed:
